# 📌 Project Overview

The **Supply Chain Analytics Dashboard** is an end-to-end Business Intelligence solution designed to provide real-time visibility into supply chain operations, inventory health, logistics performance, supplier efficiency, and revenue optimization.

This project empowers organizations to monitor critical KPIs, identify operational bottlenecks, optimize logistics costs, and drive strategic decision-making through advanced analytics and interactive visualizations.

Built with an industry-focused approach, this dashboard simulates enterprise-level reporting used by modern FMCG, Retail, Manufacturing, and E-Commerce organizations.

# 📊 Dashboard Features

## 💰 Executive KPI Monitoring

Track mission-critical supply chain KPIs in real time:

- Total Revenue
- Units Sold
- Inventory Stock
- Average Lead Time
- Shipment Time
- Defect Percentage

These KPIs provide leadership teams with a high-level operational snapshot for faster decision-making.

- Haircare
